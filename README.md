# Employee Management System

This is a simple Employee Management Web Application built using Vue.js, Axios, and MockAPI.

## Features
- Add Employee
- View Employees
- Update Employee
- Delete Employee

## Tech Stack
- Vue.js (Vite)
- Axios
- Bootstrap
- MockAPI

## How to Run
1. Install dependencies:
   npm install

2. Run the app:
   npm run dev
